# Insight Analysis Rules

Insight는 단순 요약이 아니라 기록 간의 연결 패턴을 찾고 의미를 해석하는 것을 목표로 한다.

## Core Principles

**사실과 분석의 구분**
- 기록에 명시된 사실만 인용한다.
- 기록에 없는 것을 사실처럼 생성하지 않는다.
- 추론/추정은 "~인 것 같다", "~일 가능성이 있다"로 명시한다.

**근거 중심**
- 모든 Insight는 구체적인 기록(날짜, 내용)을 근거로 제시한다.
- "반복 패턴이 있다"면 구체적인 사례를 2개 이상 제시한다.

**카테고리 간 연결 우선**
- 같은 카테고리 내 반복: 2순위
- 서로 다른 카테고리 간 영향 관계: 1순위 (더 인사이트 있음)

**시간 축 인식**
- 최근 변화와 과거 패턴을 명확히 구분한다.
- "3개월 전부터 ~로 변했다"는 구체적인 기간을 포함한다.
- 추세(점진적 변화)와 이벤트(급격한 변화)를 다르게 해석한다.

## Label-Based Analysis

label 필드는 Insight 분석의 핵심 입력이다.

- 같은 label을 공유하는 기록들은 패턴 분석 대상
- 서로 다른 label을 가진 기록들 간의 인과 관계 발견
- label 변화 추이로 관심사 변화 파악

## Insight Types

**공통 주제:** 같은 label 또는 관련 label의 기록들이 반복되는 패턴

**카테고리 영향:** Work의 스트레스가 Life/Relationship에 미치는 영향

**시간 변화:** 특정 기간의 주제/감정/행동 패턴 변화

**개인 특성:** 반복되는 행동, 결정 방식, 관계 패턴에서 드러나는 특성

## Output Format

각 Insight는:
1. 제목: 발견한 패턴을 한 줄로
2. 근거: 구체적인 기록 인용 (날짜, title/label)
3. 해석: 왜 이것이 의미 있는가
4. 변화: 시간에 따른 변화가 있는가
5. 신뢰도: "확실함" / "추정" 구분
