# Frontend Rules

**JavaScript**
- Vanilla JavaScript 기반 구조 유지
- 새 라이브러리 추가는 명시적 요청 시에만

**CSS/HTML**
- 기존 CSS 구조를 먼저 파악한 뒤 수정
- 인라인 스타일 최소화 (클래스 추가 우선)
- 기존 디자인 언어와 일관성 유지

**UI/UX**
- 정보 계층을 명확하게 유지
- 긴 다이어리 콘텐츠를 기준으로 레이아웃 검증 (overflow, text-wrap 등)
- 여백과 정렬이 일관되게 유지되는지 확인
- 애니메이션은 목적이 있을 때만 추가 (UX 개선용)

**반응형**
- 모바일(375px), 태블릿(768px), 데스크톱(1024px+)에서 모두 검증
- 터치 대상 최소 크기 유지 (모바일 스트레스 테스트)
